# 八荒大陸

> 一款為視障玩家設計的**全鍵盤文字冒險 RPG**。不用滑鼠、不看畫面，只要有 NVDA，就能自己走完整段旅程。

---

## 遊戲介紹

八荒大陸，一片被荒野吞噬的世界。八塊荒地環繞四方，妖怪橫行，不時衝入人族領地燒殺擄掠。人族與妖魔廝殺數千年，直到一位絕世天才研究出修仙之法，才避免滅族危機。

三萬年後，曾經強盛的**常恆劍宗**漸漸沒落，妖魔又開始蠢蠢欲動。故事就從凌虛峰上開始——

你扮演**葉凌天**，常恆劍宗的新收弟子，師傅是劍聖風不正。你自帶一個神秘空間：斬殺妖魔可以獲得獎勵，也能把人或妖魔帶進空間裡。

遊戲目前的內容：

- **劇情模式**：逐句朗讀開場故事，可重聽、可重播配音。
- **地圖探索**：用 `W/A/S/D` 在格子地圖上移動，走到定點按 `Enter` 觸發劇情。
- **角色資訊**：在 F1 選單裡用方向鍵逐欄查看姓名、境界、等級與各項數值。
- **無縫單視窗**：主選單、劇情、地圖全是同一個視窗在切換，視窗標題永遠是「八荒大陸」，玩家不會感覺到「跳到別的畫面」。
- **語音優先**：所有動態訊息都直接透過 NVDA 唸出來；部分句子另外錄了角色配音。

## 準備事項

- **Windows 64-bit**
- **建議安裝並啟動 [NVDA](https://www.nvaccess.org/)** — 遊戲語音播報的核心。
- 請把程式與這些檔案放在**同一個資料夾**：`萬古仙尊.exe`、`story.json`、`map.json`、`character.json`、`prism.dll`、`nvdaControllerClient64.dll`，以及 `sounds\voice\` 語音資料夾。少一個都可能讓劇情或語音出問題。

## 安裝方法

### 方法一：使用 Setup.exe（推薦）

> 下載位置**即將開放**，敬請期待。

開放之後的用法：

1. 執行 **Setup.exe**，畫面會朗讀「安裝」與「更新」兩個選項。
2. 用 **↑ / ↓** 選「**安裝**」，按 **Enter**。
3. 在資料夾選擇視窗挑一個安裝目錄，按確定。
4. Setup 會自動連到 GitHub 抓最新版本，顯示下載進度，完成後解壓安裝。

**以後要升級**：再執行 Setup.exe，選「**更新**」，並選擇**原本的安裝目錄**。它會先清掉舊版檔案，再裝上新版本。

> ⚠ 小提醒：「更新」會清空你選的那個資料夾的所有舊檔，請確實選到遊戲的安裝目錄，別選到放別的東西的資料夾，後果自行負責 😆

Setup 本身也是全鍵盤操作：**↑ / ↓** 切換、**Enter** 執行、**Esc** 離開。

### 方法二：自己下載 zip

> 下載頁面**即將開放**，敬請期待。

1. 下載並解壓 zip 到任意資料夾。
2. 執行資料夾裡的 **萬古仙尊.exe** 就開始玩。
3. 想移除遊戲，直接刪掉整個資料夾即可，不會在系統其他地方留痕跡。

如果你是從原始碼自己跑：在專案目錄執行 `dotnet run`，需要安裝 .NET 10 SDK。

## 遊戲控制

### 主選單

| 按鍵 | 功能 |
| --- | --- |
| `↑` / `↓` | 在「開始遊戲」與「結束遊戲」之間切換 |
| `Enter` | 執行目前選中的按鈕 |
| `Alt + S` | 直接開始遊戲 |
| `Alt + Q` | 直接結束遊戲 |

> 每當游標移到按鈕上，NVDA 會自動唸出按鈕名稱與說明。

### 劇情畫面

| 按鍵 | 功能 |
| --- | --- |
| `Enter` 或 `Space` | 下一句 |
| `R` | 用 NVDA 重聽目前這句文字 |
| `V` | 重聽目前這句的配音；沒有配音或音檔壞掉會自動改由 NVDA 唸 |

配音還在播的時候按 `Enter`，系統會先記住，等配音講完自動換下一句，不會漏聽也不會卡住。這時候按 `R` 或 `V`，它會先嗆你一句請你等它講完 😆

### 地圖探索

| 按鍵 | 功能 |
| --- | --- |
| `W` / `↑` | 往上走 |
| `S` / `↓` | 往下走 |
| `A` / `←` | 往左走 |
| `D` / `→` | 往右走 |
| `C` | 重聽目前座標與地點說明 |
| `Enter` | 進入目前所在地的劇情事件（沒事件會告知） |
| `G` | 聽取目前所在地的事件提示 |
| `F1` | 開啟遊戲選單 |
| `Esc` | 回主選單（**不會**結束程式） |

撞到牆或地圖邊界時，NVDA 會直接告訴你「撞到邊界了」或「前面有障礙物」。

### F1 遊戲選單

| 按鍵 | 功能 |
| --- | --- |
| `↑` / `↓` | 切換「角色資訊 / 背包 / 裝備 / 技能」 |
| `Enter` | 進入選中的項目 |
| `Alt + C` / `B` / `E` / `S` | 直接選擇角色資訊 / 背包 / 裝備 / 技能 |
| `Esc` | 返回地圖 |

### 角色資訊畫面

| 按鍵 | 功能 |
| --- | --- |
| `↑` / `↓` | 逐欄瀏覽姓名、境界、等級、HP、靈力、攻擊、防禦 |
| `Enter` 或 `Esc` | 返回遊戲選單 |

## 已知限制

- **配音尚未完成**：目前只有第一段前 5 句錄了配音，其餘句子會自動改用 NVDA 朗讀，劇情仍可正常推進；按 `V` 可以再試一次。
- **背包 / 裝備 / 技能尚未開放**：在 F1 選單按下去會聽到「功能尚未開放，敬請期待」。
- **第二段劇情尚未撰寫**：神秘空間牢籠的事件現在還不會推進，走到那裡按 `Enter` 會聽到劇情尚未撰寫的提示。
- **同一段劇情一次執行只會觸發一次**：想再聽一次請關閉遊戲重新開啟。
- **音效裝置異常時**：配音播放失敗會靜默降級回 NVDA 朗讀，不會讓遊戲崩掉。

## 常見問題

**Q：完全聽不到聲音？**
A：先確認 NVDA 已經啟動。遊戲是透過 `prism.dll` 搭配 `nvdaControllerClient64.dll` 直接驅動 NVDA；這兩個檔案要跟 exe 放在同一資料夾。如果只有某些句子沒聲音，那是配音檔還沒做好，會自動改用 NVDA 唸。

**Q：地圖上按 Enter 沒有反應？**
A：`Enter` 只在你站在事件格（例如神秘空間的牢籠）時才會進入劇情。可以先按 `C` 查目前座標，或按 `G` 聽事件提示。

**Q：按 Esc 會不會把遊戲關掉？**
A：不會。地圖上的 `Esc` 只是回主選單；要離開程式請在主選單選「結束遊戲」或按 `Alt + Q`。
